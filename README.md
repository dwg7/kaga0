# kaga0

The first implementation of Kitavolca Air-Gapped Appliance (kaga) — a portable,
network-independent appliance for displaying VBM/VLCM volcano vector tiles produced by
[kitavolca](https://github.com/hfu/kitavolca).

See [CLAUDE.md](CLAUDE.md) for full project context. Source: [UNopenGIS/7#987](https://github.com/UNopenGIS/7/issues/987).

## v0 success criteria

1. 電源投入後に直接地図が起動する (map starts directly on power-on)
2. インターネット接続なしで動作する (works with no internet connection)
3. 北海道の主要火山を表示できる (displays major Hokkaido volcanoes)
4. パン・ズームが快適である (pan/zoom feels responsive)
5. 会議や打合せで実利用できる (usable in real meetings/briefings)
