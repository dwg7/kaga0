# 1. アーキテクチャ決定記録をつける

- ステータス: 承認
- 日付: 2026-08-29

## 状況

kagaはハードウェア実機を伴うプロジェクトであり、判断の背景(なぜNative実装か、
なぜある技術を採用/不採用としたか)は時間とともに失われやすい。実装が進むにつれ、
本人(藤村さん)も含めて後から経緯を追える記録が必要。

## 決定

Michael Nygard形式のADR(Architecture Decision Record)を `docs/decisions/` に
連番で残す。1ファイル1決定。ステータスは 提案中 / 承認 / 却下 / 置き換え済み のいずれか。

## 結果

以降の重要な技術判断は、コードやコミットメッセージだけでなくADRとして残す。
